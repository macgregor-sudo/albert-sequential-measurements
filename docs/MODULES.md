# Modules

Every module of the repository, grouped by what it proves; module `A.B` is the file `src/A/B.lean`. A module marked * is imported, directly or not, by `Solution`, so the twelve compared theorems depend on it; the others prove the further results listed in the [README](../README.md) theorem map, or lemmas for them, and are built with the rest of the repository (the default targets of `lakefile.toml` build every module). The theorem map names the declarations; this file only locates them. 524 modules, 214 of them marked *.
