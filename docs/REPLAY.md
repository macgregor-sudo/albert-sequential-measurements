# Further checks and how to run them

The build, the axiom audit and the Comparator run are described in the
[README](../README.md#how-it-was-verified). This file describes the other checks: the Lean files in
`tools/checks`, which import modules of the development, and the Python scripts in `tools/`, which
recompute certificates of the papers in exact arithmetic without Lean. Run every command from the
repository root with the pinned toolchain; the Lean checks need a completed `lake build`, and the
Comparator script needs the `leanexport` and Comparator executables to be available to `lake`.

```sh
lake build
python3 tools/audit_project_axioms.py
python3 tools/audit_project_axioms.py --negative-control     # must fail on sorryAx
python3 tools/replay_comparator.py /path/to/output-directory
for check in tools/checks/*.lean; do lake env lean "$check" || exit 1; done
python3 tools/replay_bargmann_example.py
python3 tools/replay_residual_occurrences.py
python3 tools/check_residual_source_choices.py
python3 tools/replay_paper_certificates.py /path/to/public.zip
python3 tools/replay_reflected_margin.py /path/to/public.zip
python3 tools/check_eleven_tail_source.py /path/to/public.zip
```

## Importing checks

Each of the 141 files in `tools/checks` imports modules of the development, restates selected
declarations with `example`, so that their statements are checked against the source, and prints
their axioms with `#print axioms`. They exercise the declarations behind particular statements of the
papers; for example `HellyTrace.lean` covers the quaternionic Helly number of companion Corollary 4.8
and the basis independence of the positive trace, and `DepositedReferences.lean` imports the modules
of every declaration named in the margin notes of version 1 of the papers.

## Exact-arithmetic replays

`replay_comparator.py` writes fresh exports of `Challenge` and `Solution` and the axioms of the twelve
compared theorems to the output directory, runs Comparator on `comparator.json`, and requires the
positive run to pass and the run with `Challenge` as its own solution to fail on `sorryAx`.

`replay_bargmann_example.py` recomputes the four-state example of [Corrections](CORRECTIONS.md) with
rational projectors.

`replay_residual_occurrences.py` rebuilds, from the coefficient records of companion Theorem 2.4, the
324 Gram pair identities and the 7,962 signed residual occurrences of each configuration, the merged
supports of 241 words and the two printed margins; `check_residual_source_choices.py` compares the
records with the rule for the final `q` printed in version 1 of companion Appendix A.2
([Corrections](CORRECTIONS.md)).

Three scripts read the TeX sources from the source archive of version 1 of the Hexagon record
hexagon:2611.00620 (`public.zip`) and first check their SHA-256 digests: `main.tex`
`b1d6e0990bef176501af5be6a9f8c645713fd9769ff4185e859521b75b6c7670` and
`companion/macgregor-finite-certificates.tex`
`775aac59da0f202323ffdb49c629c930b19dbee9ce6a8ba18a1658c4cc7f9134`. The mathematical content they
check is the same in version 2.

- `replay_paper_certificates.py` evaluates transcriptions of the printed formulas in rational
  arithmetic and in the quadratic field generated by √2. For `M`, `S` and the reflected configuration
  it rebuilds all 784 ordered entries of each 28 × 28 Gram matrix from reduced walks; the witness
  contractions are −4/27, −2/729 and −11/1944, the last including its cross terms. The robust margins
  of `M` and `S` use the printed bucket totals. The two generators of the eleven-step words agree on
  all 2,041 words for one base and on the 8,164 words of the four-base union. Of the 1,673
  applications of companion Appendix A.4, counted with repetition, 1,118 history, base and suffix
  triples are distinct, and reducing the history together with the base leaves 1,117 keys. The
  options `--negative-control vector`, `counter` and `word` each alter one input and must make the
  corresponding comparison fail; altering either TeX file must fail the digest check.
- `replay_reflected_margin.py` checks the 22-term vector of companion Theorem 4.2 against its Lean
  transcription, expands all 484 ordered Gram pairs, 4,210 table terms and 15,468 defect terms,
  rebuilds the 5,547 nonzero words and checks the margins. With `--negative-control` it alters one
  ordered Gram coefficient and must exit 1 with `Gram coefficient or history does not match the
  deposited vector`.
- `check_eleven_tail_source.py` parses the printed table of eleven-step tails and compares its codes
  with the Lean lists.

`generate_walk_tolerance.py` regenerates the Lean files under `src/LengthSeven/WalkTolerance` from the
proofs of Lemma A; rerunning it must reproduce those files byte for byte.

## Recorded results

Results of these checks on the release commit: the six exact-arithmetic scripts pass; the 141 checking clients compile; the axiom audit accepts 38,148 exported declarations in 965 modules and its negative control fails on `sorryAx`; Comparator accepts `Solution` and rejects `Challenge` used as the solution.
